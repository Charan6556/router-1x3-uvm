# Repository preparation

The input archive was copied into a new repository layout. The original ZIP was not modified.

## Preserved content

- Five RTL files and the SVA file are byte-for-byte unchanged.
- All 27 UVM/testbench `.sv` files are retained. Nineteen files have added explanatory comments; executable source tokens are unchanged.
- Both synthesis netlists are byte-for-byte unchanged. Repeating the generic and SKY130 flows reproduced the same netlist code after ignoring comments and whitespace.
- The SDC constraints and four original result logs are byte-for-byte unchanged.
- Four supplied screenshots are retained without editing as report evidence.

## Updated supporting files

The original `run.sh` was specific to a hosted simulator environment and referred to a missing `design.sv`. It was replaced with a repository-relative launcher that uses the caller's VCS installation, writes outputs to `build/`, and optionally includes the SVA file. The new launcher has not been run with VCS; shell checks are documented separately.

The two Yosys scripts retain their synthesis pass sequence with updated source, library and output paths. `SKY130_LIB` selects the local Liberty dependency. The experimental STA script uses a configurable library path and paths relative to its own directory, while preserving the original timing commands. Its successful execution remains unverified.

The README, report summaries, reading guide, `.gitignore` and figure placeholders were added. No license was invented or assigned.

## Omitted from the clean package

| Category | Examples | Reason |
|---|---|---|
| Compiled simulator products | `simv`, `csrc/`, `simv.daidir/`, `simv.vdb/`, `vc_hdrs.h` | Regenerated by the simulator; not source or primary result evidence |
| Waveforms and transient runtime files | `dump.vcd`, `tr_db.log`, `ucli.key`, empty `vcs` | Large or session-specific artifacts |
| Hosted environment setup | `.bashrc`, `.bash_profile`, `.bash_logout`, `synopsys_sim.setup`, empty simulator library/work folders | Machine-specific configuration unrelated to the portable source layout |
| macOS metadata | `.DS_Store`, `__MACOSX/`, `._*` | Archive metadata |
| Superseded helper files | `synth.ysy`, `dump_vpd.do` | Placeholder synthesis script and optional simulator dump commands; active flows and built-in VCD generation are retained |

The preserved original ZIP remains the source for any omitted file. `reports/source_manifest.csv` maps retained project files to their original names and hashes. `reports/archive_inventory.csv` accounts for every ZIP entry and its disposition.
